# React Navigation（React 导航）

React Native 本身只负责绘制界面，它不像 Android 有：

- Activity
- Fragment
- Intent
- Back Stack

所以页面之间的跳转，需要一个第三方库来管理。

这个库就是：**React Navigation**

它负责：

- 页面跳转
- 返回上一页
- 页面历史记录
- 底部 Tab 导航
- 侧边菜单 Drawer
- 页面参数传递


## 安装

如果使用 Expo

首先需要安装 `核心功能包`:

```bash
npm install @react-navigation/native
```

然后安装依赖：

```bash
npx expo install react-native-screens react-native-safe-area-context
```
